# React + Vite

React와 Vite를 사용한 웹 프로젝트입니다.

## 🚀 웹 페이지 실행 방법

### 1. GitHub Codespaces 실행

GitHub 저장소에서 **Codespaces**를 생성하고 실행합니다.

### 2. FE 폴더로 이동

터미널에서 아래 명령어를 입력합니다.

```bash
cd FE
```

### 3. 필요한 패키지 설치

```bash
npm install
```

### 4. 개발 서버 실행

```bash
npm run dev
```

### 5. 실행 확인

터미널에 아래와 비슷한 내용이 나타나면 정상적으로 실행된 것입니다.

```text
VITE v8.2.2  ready in 503 ms

➜  Local:   http://localhost:5173/
```

Codespaces에서 표시되는 **Open in Browser** 버튼을 누르거나 제공된 주소를 열어 웹 페이지를 확인합니다.

## 📁 실행 명령어 요약

```bash
cd FE
npm install
npm run dev
```
